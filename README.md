# The Pep Talk

A tiny Node/TypeScript program for the make.fun bounty "Cat Reviews Its Human". It writes one funny single-line one-star review from a house cat about its human to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters that opens as a one-star review about the bowl.

Entry line:

> One star. The human refills the bowl on time but insists on talking to it first, like the food needs a pep talk.

Run it with: `node main.ts`
